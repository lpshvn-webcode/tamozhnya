# Таможня и склад — лендинг

Статическая страница без сборки и внешних зависимостей. Для локальной проверки:

```sh
cd /workspace/tamozhnya
python3 -m http.server 8765
```

Откройте `http://localhost:8765/` в браузере.

При отправке изменений в `main` workflow `.github/workflows/pages.yml` публикует сайт через GitHub Pages. Адрес проекта: `https://lpshvn-webcode.github.io/tamozhnya/`.

Формы готовят текст заявки, который посетитель может скопировать. Они не отправляют данные на сервер и не загружают инвойс. Перед публикацией нужно добавить подтверждённые город, компанию, контакты, адрес, график, цены и юридические документы. Номер WhatsApp можно затем подключить к кнопкам отправки.
