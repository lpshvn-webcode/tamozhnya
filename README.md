# Таможня и склад — лендинг

Статическая страница без сборки и внешних зависимостей. Для локальной проверки:

```sh
cd /workspace/tamozhnya
python3 -m http.server 8765
```

Откройте `http://localhost:8765/` в браузере.

Для публикации на GitHub Pages откройте **Settings → Pages** в репозитории и выберите **Deploy from a branch**, ветку **main**, папку **/(root)**. После включения GitHub будет публиковать изменения из `main` по адресу `https://lpshvn-webcode.github.io/tamozhnya/`.

Заглушки для замены: название компании, телефон и WhatsApp (константа `WHATSAPP` в `script.js` и ссылки `wa.me/77000000000` в `index.html`), адрес, график, цены «от … ₸», цифры в полосе доверия, кейсы, реквизиты. Параметры мини-калькулятора (курсы валют, ставки пошлины и НДС) лежат в начале `script.js`; расчёт ориентировочный. Промты для изображений: `PROMPTS.md`.

Формы готовят текст заявки, который посетитель может скопировать. Они не отправляют данные на сервер и не загружают инвойс. Перед публикацией нужно добавить подтверждённые город, компанию, контакты, адрес, график, цены и юридические документы. Номер WhatsApp можно затем подключить к кнопкам отправки.

Изображения в `assets/` сгенерированы для оформления страницы. Они не являются фотографиями реального склада, техники или клиентских проектов.
